# Modernizing Immunization Implementation Guide Gap Management with REDCap and Power BI

**CDC Public Health Informatics Fellowship Capstone | Fikru Mekonnen, MPH**

## Project Overview

The HL7 v2.5.1 Implementation Guide for Immunization Messaging supports standardized information exchange among healthcare providers, Immunization Information Systems (IIS), and public health partners.

Maintaining the guide requires an organized process for receiving, classifying, reviewing, and resolving reported gaps. The existing Google Spreadsheet-based workflow presented challenges related to data quality, version control, and tracking.

This project modernized the process through an integrated REDCap and Power BI solution.

## My Role and Contributions

As part of my public health informatics fellowship, I was assigned to support the transition from Google Spreadsheet-based gap tracking to an integrated REDCap and Power BI workflow.

My contributions included:

- Developing the REDCap component for structured submission and management of implementation-guide gaps.
- Building a five-page interactive Power BI dashboard for gap monitoring and reporting.
- Supporting the transition from the existing spreadsheet-based process to the new workflow.
- Creating dashboard views that support searching, classification, review, and tracking of reported issues.

The original spreadsheet tracking system predated my involvement.

## Solution Features

- Structured gap submissions using REDCap.
- Interactive Power BI reporting.
- Keyword search and gap classification.
- Visibility into review and resolution status.
- Identification and tracking of work items associated with proposed implementation-guide changes.

## Results

At the time of the analysis reported in my conference abstract:

- **177 gaps** were included in the integrated dataset.
- **114 gaps (64.4%)** advanced to Implementation Guide Expert Group (IGEG) review.
- **82 of 102 gaps (80.4%)** with a formal IGEG decision were accepted for the next implementation-guide release.
- **28 work item categories** were identified.

These are descriptive results from the gap-review process; they should not be interpreted as improvements caused solely by the dashboard.
